### ¿Qué es FastAPI?

FastAPI es un **framework moderno y rápido** para construir APIs web en Python. Piensa en él como una herramienta que te permite crear servicios web (APIs) de manera muy eficiente y con poco código.

Una analogía: Si construir una API con otras herramientas es como hacer una casa ladrillo por ladrillo, con FastAPI es como usar bloques prefabricados: es más rápido, más ordenado y el resultado es muy profesional.
